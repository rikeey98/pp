# Insights from Rights and Wrongs: A Large Language Model for Solving Assertion Failures in RTL Design

## 논문 정보
- **제목**: AssertSolver
- **출판**: arXiv preprint, 2025년 3월
- **arXiv ID**: 2503.04057
- **링크**: https://arxiv.org/html/2503.04057v1

## 연구 개요

AssertSolver는 RTL(Register Transfer Level) 설계에서 발생하는 **assertion failure를 자동으로 해결**하기 위해 특별히 설계된 오픈소스 Large Language Model입니다. 하드웨어 검증 과정에서 발생하는 assertion 오류를 자동으로 분석하고 수정하는 최초의 전문 LLM입니다.

## 연구 배경

### Assertion Failure의 중요성
- **RTL 검증**: 하드웨어 설계 검증의 핵심 과정
- **Assertion**: 설계가 만족해야 할 속성 명시
- **Failure**: Assertion 위반 시 발생
- **수동 디버깅**: 현재는 전문가의 수동 분석 필요

### 기존 문제점
- **시간 소모적**: 숙련된 엔지니어도 수 시간~수 일 소요
- **전문성 요구**: 높은 수준의 하드웨어 설계 지식 필요
- **반복적**: 유사한 오류도 매번 수동 분석
- **자동화 도구 부재**: 현재 assertion failure를 자동으로 해결하는 도구 없음

## 핵심 기술

### 1. 전문 LLM
- **특화 설계**: RTL assertion failure 해결에 특화
- **오픈소스**: 공개되어 누구나 사용 가능
- **학습 데이터**: 실제 assertion failure 사례 학습

### 2. Rights and Wrongs 학습
- **Right (올바른 사례)**: 정상적으로 동작하는 RTL 코드
- **Wrong (오류 사례)**: Assertion failure가 발생한 코드
- **대조 학습**: 올바른 코드와 오류 코드의 차이 학습
- **패턴 인식**: 일반적인 오류 패턴 학습

### 3. 자동 버그 수정
- **입력**:
  - RTL 코드
  - Assertion 명세
  - Failure 메시지
- **출력**:
  - 수정된 RTL 코드
  - 수정 설명
- **프로세스**:
  1. Assertion failure 분석
  2. 원인 파악
  3. 수정 방안 생성
  4. 검증

## 성능 결과

### 테스트벤치 성능
- **Pass@1 성공률**: **88.54%**
  - 첫 번째 시도에서 88.54% 성공
  - 매우 높은 정확도

### 기존 모델과 비교
- **OpenAI o1-preview 대비**: **11.97% 향상**
- **일반 LLM**: Assertion failure 해결에 특화되지 않음
- **AssertSolver**: 전문 학습으로 월등한 성능

### 의미
- **자동화 가능성**: 대부분의 assertion failure 자동 해결 가능
- **시간 절감**: 수 시간~수 일 → 몇 분
- **품질**: 인간 전문가 수준의 수정

## 적용 분야

### RTL 검증 자동화
- **회귀 테스트**: Assertion failure 자동 수정
- **야간 빌드**: 밤새 발생한 오류 자동 해결
- **지속적 통합**: CI/CD 파이프라인에 통합

### 설계 디버깅
- **빠른 수정**: 즉각적인 버그 수정 제안
- **학습 도구**: 초보자가 오류 패턴 학습
- **생산성**: 엔지니어가 복잡한 문제에 집중 가능

### SoC 검증
- **대규모 검증**: 많은 assertion이 있는 SoC 검증
- **자동 해결**: 반복적인 assertion failure 자동 처리
- **품질 향상**: 더 많은 오류 탐지 및 수정

## 기술적 세부사항

### 학습 방법론

#### 대조 학습 (Contrastive Learning)
- **정상 코드**: Assertion을 통과하는 코드
- **오류 코드**: Assertion failure 발생 코드
- **차이 학습**: 무엇이 문제인지 학습

#### 패턴 인식
- **일반적인 오류**: 자주 발생하는 assertion failure 패턴
- **수정 전략**: 각 패턴에 대한 해결 방법
- **일반화**: 새로운 사례에 적용

### 모델 아키텍처
- **Transformer 기반**: 최신 LLM 아키텍처
- **RTL 특화**: Hardware description language 이해
- **다중 작업**: 분석, 진단, 수정 통합

## 결론

AssertSolver는 RTL 설계의 assertion failure를 자동으로 해결하는 최초의 전문 LLM으로, 88.54%의 높은 성공률을 달성하여 기존 범용 모델 대비 11.97% 향상된 성능을 보입니다. 오픈소스로 공개되어 하드웨어 검증 커뮤니티 전체가 활용할 수 있으며, RTL 검증 자동화의 새로운 장을 열었습니다. 이는 SoC 검증 엔지니어의 생산성을 크게 향상시키고, 반복적인 디버깅 작업에서 해방시켜 더 복잡하고 가치 있는 문제 해결에 집중할 수 있게 합니다.

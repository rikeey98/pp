# Debug Smarter, Not Harder: AI Agents for Error Resolution in Computational Notebooks

## 논문 정보
- **저자**: Multiple authors
- **학회**: EMNLP 2024 (Conference on Empirical Methods in Natural Language Processing) - Demo Track
- **출판**: ACL Anthology

- **링크**: https://arxiv.org/abs/2410.14393

## 연구 개요

계산 노트북(Computational Notebooks)에서 발생하는 오류를 자동으로 해결하기 위한 AI 에이전트 시스템입니다. Jupyter Notebook, Google Colab 등에서 발생하는 코드 오류를 **사용자가 노트북을 사용하는 것처럼** 환경과 상호작용하며 자동으로 디버깅합니다.

## 연구 배경

### Computational Notebooks
- **정의**: Jupyter Notebook, Google Colab 등 대화형 코딩 환경
- **특징**:
  - 코드, 텍스트, 시각화 혼합
  - 셀 단위 실행
  - 데이터 과학 및 연구에 널리 사용

### 기존 문제점
- **빈번한 오류**: 코드 실행 중 다양한 오류 발생
- **수동 디버깅**: 사용자가 직접 오류 분석 및 수정
- **시간 소모**: 특히 초보자는 많은 시간 소요
- **학습 곡선**: Python, 라이브러리 등 학습 필요

## 핵심 기술

### 1. Agentic System (에이전트 시스템)
- **자율성**: 사용자 개입 없이 자동으로 작동
- **환경 상호작용**: 노트북 환경과 직접 상호작용
- **반복 학습**: 시행착오를 통한 문제 해결

### 2. 환경 탐색 (Environment Exploration)
AI 에이전트가 **사용자처럼** 노트북 환경 탐색:

#### 가능한 행동
- **셀 실행**: 코드 셀 실행
- **변수 검사**: 변수 값 및 타입 확인
- **라이브러리 확인**: 설치된 패키지 확인
- **파일 시스템**: 파일 존재 여부 확인
- **오류 분석**: 오류 메시지 읽기

#### 상호작용 방식
```
1. 오류 발생 감지
2. 환경 상태 파악 (변수, 라이브러리 등)
3. 가능한 원인 추론
4. 수정 시도
5. 재실행 및 검증
6. 성공할 때까지 반복
```

### 3. JetBrains Datalore 통합
- **실제 배포**: JetBrains Datalore에 통합
- **Datalore**: 협업 데이터 과학 플랫폼
- **실사용자**: 실제 사용자들이 활용
- **피드백**: 실제 사용 데이터 수집

## 주요 기능

### 오류 탐지
- **자동 감지**: 셀 실행 시 오류 자동 탐지
- **오류 분류**: 오류 유형 식별
- **컨텍스트 수집**: 관련 코드 및 환경 정보 수집

### 오류 분석
- **근본 원인**: 오류의 실제 원인 파악
- **의존성 추적**: 이전 셀과의 관계 분석
- **패턴 인식**: 일반적인 오류 패턴 식별

### 자동 수정
- **수정 제안**: 여러 수정 방안 생성
- **안전한 적용**: 부작용 최소화
- **검증**: 수정 후 재실행으로 확인

### 사용자 인터페이스
- **통합 UI**: 노트북 내 원활한 통합
- **실시간 피드백**: 진행 상황 표시
- **설명 제공**: 무엇을 왜 수정했는지 설명

## 시스템 아키텍처

### 1. Observation Layer (관찰 계층)
- 노트북 환경 상태 모니터링
- 오류 및 이벤트 감지
- 환경 정보 수집

### 2. Reasoning Layer (추론 계층)
- LLM 기반 오류 분석
- 원인 추론
- 해결 전략 수립

### 3. Action Layer (행동 계층)
- 노트북 환경 조작
- 코드 수정
- 셀 실행

### 4. Verification Layer (검증 계층)
- 수정 결과 확인
- 부작용 검사
- 성공/실패 판단

## 적용 사례

### 일반적인 오류 유형

#### 1. 라이브러리 누락
```python
# 오류: ModuleNotFoundError: No module named 'pandas'
import pandas as pd

# AI 에이전트 해결:
!pip install pandas
import pandas as pd
```

#### 2. 변수 미정의
```python
# 오류: NameError: name 'data' is not defined
result = data.mean()

# AI 에이전트: 이전 셀에서 data 로드 필요 감지
# → 사용자에게 알리거나 자동으로 이전 셀 실행
```

#### 3. 타입 불일치
```python
# 오류: TypeError
x = "123"
y = x + 456

# AI 에이전트 수정:
x = "123"
y = int(x) + 456
```

#### 4. 파일 없음
```python
# 오류: FileNotFoundError
df = pd.read_csv('data.csv')

# AI 에이전트: 파일 존재 확인 → 경로 수정 또는 대안 제시
```
